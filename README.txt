# Rakshabandhan Interactive Website

Open `index.html` in a browser.

## Customize your photos
Replace the files in `assets/` with your own JPG/PNG photos while keeping the same filenames, or edit the image filenames in `index.html`.

The site is responsive and includes:
- Animated landing page
- Yes/No surprise interaction
- Clickable gifts
- Best Sister award
- Photo/memory gallery with lightbox
- "You are my..." page
- Personal letter
- Replay button

The included assets were extracted from the uploaded reference video so you can see the layout immediately.
